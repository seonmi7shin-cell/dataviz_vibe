# dataviz_vibe · 코드 생성 실습 프로젝트

Claude Code에 자연어로 지시해 분석 코드를 직접 생성하는 실습 폴더입니다. 파이썬 파일이 없는 상태에서 시작합니다.

```
D:\dataviz_vibe\
├── data\        원본 CSV 5종. 제공 프로젝트와 동일한 파일
├── output\      생성한 표와 차트
├── scripts\     생성한 파이썬 코드
└── CLAUDE.md    코드 작성 규칙과 산식 정의
```

## 폴더를 분리한 이유

`D:\dataviz`에는 완성된 실습 스크립트가 있습니다. 같은 폴더에서 코드를 생성하면 두 가지 문제가 발생합니다.

- 생성 파일명이 제공 스크립트와 중복됩니다.
- 도구가 제공 스크립트를 수정해 기준 결과를 재현할 수 없게 됩니다.

폴더를 나누면 제공 스크립트가 원형을 유지하므로, 생성 결과가 기대와 다를 때 언제든 기준 결과와 대조할 수 있습니다.

## 데이터 동일성

`data` 폴더의 CSV는 제공 프로젝트와 내용이 완전히 같습니다. 같은 지시에 같은 값이 나와야 하며, **생성 결과와 제공 스크립트 결과를 대조하는 것**이 이 실습의 검증 방법입니다.

| 파일 | 규모 |
|------|------|
| `01_핀테크결제_dirty.csv` | 12,150행 8열 |
| `핀테크_정제완료.csv` | 11,713행 8열 |
| `02_SaaS구독매출.csv` | 2,500행 7열 |
| `03_ICT기업주가.csv` | 1,566행 7열 |
| `04_카드소비_지역업종.csv` | 1,632행 5열 |

## 준비 · 이 폴더 전용 가상환경

제공 프로젝트와 라이브러리를 섞지 않도록 상자를 따로 둡니다. 한쪽에서 버전을 올려도 다른 쪽은 그대로 남습니다.

```powershell
D:
cd \dataviz_vibe

python -m venv dataviz-vibe-env
dataviz-vibe-env\Scripts\activate

pip install pandas numpy matplotlib seaborn plotly streamlit openpyxl reportlab
```

프롬프트 앞에 `(dataviz-vibe-env)` 가 붙은 것을 확인하고 진행합니다. **이 표시가 없는 창에서 도구를 띄우면 pandas 를 찾지 못합니다.**

## 진행 순서

1. `(dataviz-vibe-env)` 표시를 확인한 창에서 `claude`를 실행합니다.
2. 앞서 확인한 결과를 자연어로 지시합니다.

   ```
   > @data\핀테크_정제완료.csv 업종별 거래금액 합계를 큰 순으로 막대그래프 그려 줘
   ```

3. 도구가 `scripts` 폴더에 파이썬 파일을 만들고 실행합니다.
4. 제공 스크립트 실행 결과와 수치를 대조합니다. 코드 구조는 달라도 값이 같으면 재현에 성공한 것입니다.
5. 생성한 코드를 커밋하고 원격 저장소에 반영합니다.

## 지시할 때 알아야 하는 것

문법은 도구가 작성합니다. 사람이 판단할 것은 **어떤 방법으로 집계하고 어떤 차트로 표현할지**입니다.

「업종별로 묶어 합계를 내고 큰 순으로 막대그래프」 수준의 문장이면 충분합니다. 차시마다 제공하는 메서드·함수 명세서가 이 판단의 근거입니다.

대상 파일은 `@`로 지정합니다. 목록에서 골라 자동 완성되므로 경로 오타가 발생하지 않습니다.

## 코드 품질은 규칙 파일이 담보합니다

`CLAUDE.md`에 다음이 정의되어 있어 지시할 때마다 반복해서 말할 필요가 없습니다.

| 항목 | 내용 |
|------|------|
| 실행 위치 | 어느 폴더에서 실행해도 `data`를 찾도록 경로 처리 |
| 주석 | 왜 그렇게 쓰는지, 빼면 어떻게 되는지까지 기재 |
| 차트 | 한글 폰트와 마이너스 기호 설정 |
| 저장 위치 | 표는 `output`, 차트는 `output/charts`, 코드는 `scripts` |
| 산식 | 비율은 백분율 소수점 둘째 자리 등 |

규칙 파일을 고치면 이후 생성되는 모든 코드에 반영됩니다.

## 이력 관리

생성한 코드는 커밋하고 GitHub에 반영합니다. 규칙 파일에 원격 저장소가 지정되어 있으므로 지시 한 줄로 처리됩니다.

```
> 지금까지 만든 거 커밋하고 올려 줘
```

`output` 폴더는 `.gitignore`로 제외됩니다. 코드를 다시 실행하면 만들어지는 산출물이기 때문입니다. 원본 데이터는 저장소에 포함되어 있어, 다른 환경에서 내려받아도 바로 실행할 수 있습니다.
